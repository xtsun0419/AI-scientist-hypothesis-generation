多 Agent 架构图

OrchestratorAgent

总调度器：创建 run，控制阶段顺序、失败标记和子 Agent 调用。

DomainQueryAgent

领域查询规划：从配置生成永磁领域 QueryPlan。

SourceDiscoveryAgent

多源检索：调用数据源 connector，写入原始记录。

MetadataNormalizeAgent

元数据清洗：把不同来源 payload 转成候选文献。

DeduplicationAgent

去重合并：优先按 DOI，其次按标题和年份合并。

RelevanceJudgeAgent

相关性判断：用可审计规则给永磁相关性打分。

OAResolverAgent

获取状态解析：补 DOI URL、出版商页、OA 状态和 PDF URL。

PdfDownloadAgent

PDF 下载：只下载开放或明确公开的 PDF，并记录哈希。

QualityAuditAgent

质量审计：检查缺 DOI、低相关、PDF 异常等问题。

ReportExportAgent

报表导出：生成 CSV、JSONL、BibTeX、Markdown 和 HTML 工作台。

多 Agent 工作关系框架图

调度层
OrchestratorAgent读取配置，创建 run，按 DAG 调用各 Agent，记录失败与完成状态。
CLI 命令search / resolve-oa / download / audit / report / dashboard
领域配置永磁词表、数据源、年份范围、每个 query 的结果上限。

断点续跑每个阶段都可单独运行，复用 SQLite 中间状态。
Orchestrator 按阶段推进，所有 Agent 通过 SQLite 交换状态
Agent 执行层
Query生成永磁领域检索式。
Discovery连接 OpenAlex、Crossref、Semantic Scholar、arXiv 等来源。
Normalize统一 DOI、标题、作者、年份、期刊、PDF URL。
Dedup合并重复文献，保留全部来源证据。
Relevance判断是否真的属于永磁领域。
OA Resolver区分开放、非开放、有 DOI、缺 DOI。
PDF Download只下载开放或明确公开 PDF。
Quality Audit检查缺 DOI、低相关、PDF 异常。
Report / HTML生成 CSV、JSONL、BibTeX、Markdown 和本工作台。
LLM 边界复核只复核规则分数中间区间或证据不足的样本。
结构化数据进 SQLite，大文件进 PDF 文件库，最终产出报表
共享状态与文件层
source_records保存每个来源返回的原始 payload。
paper_candidates保存标准化后的候选文献。
papers去重后的主文献库。
access_recordsDOI、DOI URL、出版商页、OA 状态、PDF URL。
pdf_assetsPDF 本地路径、哈希、大小、下载状态。

缺 DOI 清单missing_doi.csv，用于人工补全。
