# 提出路线 / 候选 Agent

这是 AI Scientist 工作流的第 4 个模块。它读取第 1 模块创建的科学问题、第 3 模块归纳出的方向，以及第 2 模块的 Paper Cards / Wiki 证据，生成若干条可执行研究路线候选。

当前初版已经接入 8765 前端：

- 页面路径：`http://127.0.0.1:8765/route-candidates`
- 数据输出：`04_提出路线/data/route_candidates.json`
- 输入：科学问题下拉选择、路线数量、研究偏好补充
- 输出：候选路线、材料/结构候选、关键变量、验证方式、证据依据、风险和下一步

如果已配置外部 LLM API，会优先调用 LLM 生成严格 JSON；如果没有配置或调用失败，会使用本地规则生成可编辑草稿。
