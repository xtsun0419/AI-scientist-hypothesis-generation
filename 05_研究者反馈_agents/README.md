# 研究者反馈 Agent

本模块维护一个可选的“更新后文献库”，用于支持研究者反馈和路线设计。

## 数据边界

- `personal`：研究者导入的 PDF、Markdown、文本或 JSON 文献，保留本地路径作为来源。
- `agent`：由第 01 模块检索并同步的论文元数据。
- 两类条目统一存入 `data/researcher_library.sqlite`，但始终保留来源类型。

## 上下文隔离

研究者模拟 Agent 只读取文献库条目的标题、摘要和文本摘要，生成一个可证伪的下一步提问。它不读取第 03 模块对话、第 04 模块路线、Critic 评审或其他模拟提问。

第 04 模块仅在“启用模拟研究者”后读取文献库的证据快照。它不会读取模拟提问记录或第 03 模块会话。研究者可以自行决定是否将提问内容带入问题归纳对话。

## 使用方式

在 `http://127.0.0.1:8765/researcher-library`（本地开发服务可使用 8766 端口）中：

1. 导入个人文献所在文件或目录。
2. 同步第 01 模块的检索结果。
3. 开启模拟研究者，再生成提问。

“自动对话并生成假设”会先由研究者模拟 Agent 发出公开问题，再由独立设计者仅基于同一文献快照和这条公开问题生成可检验假设与验证方案。

第 01 模块在成功检索或规划一轮候选后，会自动同步已有论文元数据。
